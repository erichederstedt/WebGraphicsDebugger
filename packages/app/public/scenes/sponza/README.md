# Dabrovic Sponza

Source: https://casual-effects.com/g3d/data10/research/model/dabrovic_sponza/sponza.zip
Archive: Morgan McGuire, Computer Graphics Archive, July 2017, https://casual-effects.com/data/

Original attribution is preserved in copyright.txt. Material texture paths have
been corrected to match the archive filenames on case-sensitive filesystems.
The demo uses diffuse colors and diffuse textures; bump maps are retained but
are not rendered.
